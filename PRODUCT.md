# Product context

## Register
Product: a local creative prompt workbench with Photoshop integration.

## Users and purpose
Creators configure chat models to generate and refine prompts. API settings must work in the narrow desktop window as well as a browser.

## Design principles
Preserve the existing neutral theme and interface. Keep settings compact, readable and keyboard accessible. Long model lists must stay within the viewport and support search. Image, audio and video generation models do not belong in the chat model picker. Preserve manual model ID entry for custom providers.
