影词魔方 + Photoshop 局部改图

安装：
1. 先完整解压本 ZIP。
2. 双击“安装.cmd”。
3. 安装完成后，在自动打开的影词魔方页面进入“API 设置”，填写并保存自己的 API 信息。
4. 重新启动 Photoshop，从“增效工具”打开“局部改图”。
5. 在“修改要求”右侧点击“✨ 优化”。

日常使用：
- Windows 登录后影词魔方连接器会自动在后台启动。
- 开始菜单“影词魔方”中可以打开工作台、启动连接器或卸载。
- 影词魔方数据保存在本机安装目录的 app\local-data 中。
- API Key 只保存在本机 app\.env.local，不会写入 Photoshop 插件。

换电脑：
- 在新电脑重新运行同一个安装包。
- 重新填写 API 设置。
- 如需迁移历史和风格库，复制旧电脑的 app\local-data 文件夹。
