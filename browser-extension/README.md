# PromptCinema 浮窗扩展

在任意网页按快捷键唤起 AI 提示词增强小窗，调用你已部署的 `enhancePrompt` 接口。

## 一、加载扩展

1. 把整个 `browser-extension` 文件夹下载到本地（任意位置）。
2. 打开 Chrome / Edge：地址栏输入 `chrome://extensions`。
3. 右上角打开「开发者模式」。
4. 点「加载已解压的扩展程序」，选择 `browser-extension` 文件夹。

## 二、配置接口地址

1. 在扩展列表里点 PromptCinema 下方的「详情 → 扩展选项」（或点小窗里的"设置"）。
2. **enhancePrompt 接口地址**：打开你的完整应用，按 F12 → Network，触发一次"优化生成"，复制 `enhancePrompt` 请求的完整 URL 粘贴进来。
3. **完整应用地址**：填你的应用首页 URL（点小窗 ⤢ 时打开完整软件）。

## 三、自定义快捷键

1. 打开 `chrome://extensions/shortcuts`。
2. 找到「打开/关闭提示词增强浮窗」，默认 `Ctrl+Shift+E`（Mac 为 `Command+Shift+E`）。
3. 点输入框，按下你想要的组合即可覆盖。

## 四、使用

在任意网页按快捷键 → 右上角弹出增强小窗：选方向 / 模型 / 目标引擎 → 输入灵感 → 点"优化生成"，英文提示词自动复制到剪贴板，同时显示中文版与标签。

## 注意

- **登录态**：小窗通过接口直接调用后端，需要你已在浏览器中登录过完整应用。若提示"未登录"，点 ⤢ 打开完整应用登录后重试。
- **图片反推 / 多图 / 视角模式**：这些需要上传图片，请在完整应用中使用，小窗暂只支持文字增强。
- 小窗仅能在普通网页（http/https）上唤起，浏览器系统页（chrome://）无法注入。
